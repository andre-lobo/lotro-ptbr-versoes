# LOTRO PT-BR — versões

Versões publicadas de uma tradução **pessoal e não oficial** de *The Lord of the Rings Online* para o português do Brasil.

Os pacotes (`lotro-ptbr-X.Y.Z.zip`) ficam nas [Releases](../../releases) e são instalados pelo aplicativo **LotroPtBr**,
que também desinstala e devolve o jogo exatamente ao original.

- Os pacotes contêm apenas o texto traduzido, sem nenhum arquivo do jogo.
- Projeto de fã, sem fins lucrativos, sem vínculo com a Standing Stone Games ou a Middle-earth Enterprises.
- Modificar o cliente contraria o EULA do jogo; use por sua conta e risco.
